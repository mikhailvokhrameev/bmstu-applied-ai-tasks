# Эталоны и квалификация

Метрики и ручные эталоны описаны в [методике](METHODOLOGY.md), фактические версии —
в [среде](ENVIRONMENT.md). Команды выполняются из корня репозитория или
распакованного канонического комплекта с Python 3.10+ и установленными JAR:

```sh
python3.11 -m lab4.assessment.verify_reference
python3.11 -m lab4.assessment.test_verify_reference
```

Порядок установки JAR и пути обоих вариантов приведены в
[руководстве оператора](../docs/OPERATOR.md). Подготовка контрольных текстов также
вызывается модулем: `python3.11 -m lab4.assessment.build_context_pairs --help`.
Она не вызывается повторно для уже зафиксированной серии.

| Онтология | A | Al | C | H | Po | Pd | E | Q | F формулы |
|---|---|---|---|---|---|---|---|---|---|
|01-balanced|18|6|2|1|1|1|1|1|1.437923490|
|02-zero|8|2|1|0|1|0|0|1|0.894960474|
|03-pitfalls|23|6|4|2|1|1|1|6|1.179252234|

Это примеры расчёта, а не допустимые кандидаты относительно неизменяемого ядра.
Точные дроби находятся в fixtures/expected.json и CSV.

Все 20 исходных меток concept_pairs.csv сохранены после
[предметной проверки ИИ](AI_REVIEW.md). До измерений новых моделей определения
«метка. комментарий» и дополнительный набор зафиксированы в
[CONTEXT_PREREGISTRATION.json](CONTEXT_PREREGISTRATION.json). Определения основаны
на онтологии; синонимы одного понятия используют общее определение. Малый
полусинтетический набор не доказывает качество на любых новых понятиях.

Для основных серий выбрана multilingual-E5-large-instruct с фиксированной
STS-инструкцией и порогом 0.960735025415394: 0 ошибок на 20 обязательных парах
и 0 на 20 дополнительных. Порог выбран по обязательному набору до debug;
дополнительный набор его не менял. [Квалификация Т04](evidence/qualification-v4.json)
и [описание моделей](../optimizer/MODELS.md) фиксируют реальные результаты,
версии и SHA-256. Наборы и модели после начала серий не меняются.

Выполнение Т01–Т12 отражено в [протоколе](../docs/ACCEPTANCE_STATUS.md).
Независимая проверка официальным OOPS REST и объяснение расхождения P04
находятся в [доказательствах](evidence/oops-baseline-reference/README.md).
