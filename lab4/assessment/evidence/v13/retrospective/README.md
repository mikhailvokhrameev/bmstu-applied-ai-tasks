# Оценка сохранённых кандидатов

Численные показатели рассчитаны для всех 1700 кандидатов `lab4/runs/series-v1`
без запуска нейросетей и Java. M1–M5 сверены с исходными журналами с допуском
`1e-12`; Q и статусы логической и семантической допустимости взяты из журналов.
Добавлены все 15 структурных метрик, коэффициенты, B, S и F.

- `best-recalculation.json` — полный набор показателей десяти лучших кандидатов.
- `all-recalculation-summary.json` — покрытие и изменения оценок.
- `recalculation-statistics.json` — медианы и точный односторонний тест Манна–Уитни.
- `selection-replay.json` — проверка траекторий контрольного генератора.
- `change-kind-review.json` — 12 вариантов, требующих отдельного предметного решения.
- `curves.json`, `reassessment.png` — значения и графики для отчёта.

Лучшие ID среди допущенных исходными проверками кандидатов сохранились.
Медианы F: model — 1.3230400562895064, control — 1.0967452893530962;
U = 25, p = 0.003968253968253968.

Это оценка полученной выборки. При новой F траектория `control-202` расходится
с архивом во втором поколении; результаты не означают проведения новых серий.

Для воспроизведения из корня репозитория с активной Python-средой:

```sh
python lab4/assessment/evidence/v13/retrospective/recalc_offline.py --output /tmp/videocard-reassessment-check
python lab4/assessment/evidence/v13/retrospective/replay_selection.py --output /tmp/videocard-selection-check.json
```

Без `--output` скрипты создают отдельную временную папку. Исходные журналы
не изменяются. Эти команды не возобновляют остановленную серию v1.3.
