# Проверка версии 2.0.0 в Protégé Desktop

В настоящем Protégé Desktop 5.6.9 проверен файл версии 2.0.0 с SHA-256
`b94f610553856340c6770c1fb0a061c3aef719ee95aae7262fa919a6ef0780bb`.
Исходный файл остался неизменным. Использованы установленный HermiT, настоящий
OWLModelManager и штатная вкладка DL Query приложения.

Все шесть проверочных случаев прошли. Для основной онтологии и после её
RDF/XML-сохранения выполнены все 23 варианта контрольных вопросов через parser/API
приложения и ещё раз через кнопку Execute и фактический список результатов DL Query:
всего 92 точных сравнения множеств индивидов. Невыполнимых пользовательских классов
нет; онтология согласована. Аксиомы, ID, аннотации и метрики после roundtrip совпали.

| Метрика GUI | Значение |
|---|---|
| Аксиомы | 508 |
| Логические аксиомы | 271 |
| Классы с owl:Thing | 16 |
| Пользовательские классы | 15 |
| Объектные свойства | 16 |
| Свойства данных | 7 |
| Индивиды | 41 |

Отрицательные копии T06–T08 признаны противоречивыми: активное и пассивное
охлаждение одновременно, два различных GPU, отрицательный объём памяти.
В T09 удалено asserted hasMemory у U05: HermiT сохранил согласованность при
открытом мире, а отсутствие обязательного утверждения зафиксировано отдельно.
Карточка полноты проверяется также общим локальным harness.

[Основной машинный результат](evidence.json), [запуск и происхождение](launch.json),
[визуальная проверка ИИ](visual-review.json), [метрики настоящего окна](source/window.png)
и [пример запроса после roundtrip](T10-dl-query/23-Q8__raw_cross-check_/window.png)
содержат доказательства. Все четыре отрицательные копии, снимки, текст интерфейса
и результаты каждого запроса сохранены рядом. Снимки получены отрисовкой только
собственных окон приложения; чужие окна и рабочий стол не захватывались.

IRI онтологии сохранён; version IRI и owl:versionInfo равны 2.0.0. Исходная
описательная аннотация с упоминанием 1.0.0 сохранена от базовой версии; номер
выпуска определяется version IRI и owl:versionInfo.

[Helper и порядок воспроизведения](../protege-api/README.md) описывают публичные
API и установку. Название плагина HermiT — 1.4.3.456, self-report движка —
1.4.1.432; оба значения сохранены как получены.
