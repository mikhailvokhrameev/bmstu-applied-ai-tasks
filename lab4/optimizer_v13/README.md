# Расчёт по ТЗ 1.3

Отдельная версия программы с 15 структурными метриками, B/S/F, проверкой циклов
и ограничения S, полными журналами и воспроизведением. Исходный `optimizer`
и завершённые `series-v1` сохранены без изменений.

Для ускорения используются один Java-процесс и кеши точных реконструкций
и завершённых проверок. Бюджет и все строки журнала сохраняются.

Фактические данные `lab4/runs/series-v13`:

- `debug-100` завершён: 34 оценки, три поколения, лучший F = 1.1246297491328545.
- `model-101` остановлен по поручению пользователя: сохранены 25 оценок;
  контрольная точка содержит 18 оценок и завершённое поколение 1.
- Остальные запуски этой серии не выполнялись.

Все серверы моделей остановлены. Эти данные не являются завершёнными
основной и контрольной сериями по ТЗ 1.3.

Для завершённой `series-v1` отдельно подготовлена
[оценка сохранённых кандидатов](../assessment/evidence/v13/retrospective/README.md).
Сокращённый [Word-отчёт](../docs/otchet_lr4_videocard_nn_v1.3_short.docx)
содержит метрики, графики и область подтверждённых результатов.

Формулы, параметры и исходники фиксируются в метаданных запуска. Изменение
обработки ошибки неизвестного префикса в debug оформлено отдельным
`source-migration.json`; исходные метаданные и полученные ответы сохранены.

Установка Python и Java описана в [руководстве оператора](../docs/OPERATOR.md).
Команды версии 1.3 используют пространство имён `lab4.optimizer_v13`.
Поэтапный запуск предусмотрен модулем `lab4.scripts.run_v13_part`,
но остановленные вычисления возобновляются только по явному поручению.
