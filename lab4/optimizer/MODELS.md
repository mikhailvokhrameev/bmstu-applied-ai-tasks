# Выбранные модели и квалификация

Конфигурация зафиксирована 2026-11-02 до основной и контрольной серий.
Используются локальные сервисы: Ollama 0.40.13 на 127.0.0.1:11435 и исходная
SentenceTransformer multilingual-E5 на 127.0.0.1:11437. Облачная генерация отключена.

| Назначение | Модель | Подтверждение |
|---|---|---|
| Генерация | qwen2.5-coder:7b, Q4_K_M | Фактические веса 4683074048 байт, SHA-256 `60e05f2100071479f596b964f89f510f057ce397ea22f2833a0cfe029bfc2463` |
| Эмбеддинги | intfloat/multilingual-e5-large-instruct | HF commit `274baa43b0e13e37fafa6428dbc7938e62e5c439`, полный Transformer → mean pooling → Normalize |

Каждый файл весов E5 и inference assets проверен независимо от HTTP metadata.
Общий SHA-256 manifest inference assets — `071e12c3e0013df6ee8b248bb46d1acadbd9e79a3c33478e194ce72ff0244063`.
Файлы весов:

- `model.safetensors`: 1119825680 байт, SHA-256 `dd6b6e4f52db0a7aff83a13d10e6c5342ef9f6ab799bad3221f4b35ef390fa85`.

Полные manifests, версии библиотек, scores и входные тексты находятся в
[context-e5-preflight/preflight.json](../assessment/evidence/context-e5-preflight/preflight.json).
Модель E5 не конвертировалась в другой pooling; веса не обучались и не дообучались.
Сервис загружает закреплённый локальный snapshot без remote code и без токена HF.

Параметры LLM: temperature=0.7, top_p=0.95, num_predict=2000, num_ctx=32768.
Отдельный seed каждой мутации берётся из сохраняемого RNG, retries сохраняют seed.
В каждый запрос входит полный Manchester-документ с префиксами и заголовком,
все текущие аксиомы, метрики, ri, разрешённые изменения, фактические нарушения,
операнды прямых/обратных отношений и сохранённая оценка выбранного родителя.
Ответы не исправляются программой ради зачёта первой попытки.

Вектор строится из «метка. комментарий» с одной стандартной STS-инструкцией E5:
`Instruct: Retrieve semantically similar text.
Query: <метка. комментарий>`.
Одинаковая инструкция применяется ко всем текстам, без правил по ID/метке пары.
Сравниваются сущности одной категории OWL. Кеш разделён по backend, модели,
инструкции, категории и точному тексту; сбои не кешируются.

## Контрольные данные и решение ИИ

Исходные 20 коротких пар и все метки сохранены. До новых измерений отдельно
зафиксированы полные определения из онтологии и дополнительный набор:
[CONTEXT_PREREGISTRATION.json](../assessment/CONTEXT_PREREGISTRATION.json).
Синонимы одного понятия имеют общее определение — это ограничение небольшого
полусинтетического набора, а не независимая оценка всей предметной области.
Подробная проверка ИИ находится в [AI_REVIEW.md](../assessment/AI_REVIEW.md).

E5 при исходном пороге 0.90 дала 3 ошибки. Минимальный score
синонима — 0.9616981956378192, максимальный score разных понятий —
0.9597718551929688. ИИ выбрал середину разделяющего интервала:
**0.960735025415394**. При нём 0 ошибок из 20 обязательных пар и
0 из 20 дополнительных; дополнительный набор не менял порог.
[Решение по порогу](../assessment/evidence/context-e5-preflight/AI_THRESHOLD_DECISION.json)
принято до debug и серий. Метки/тексты не подгонялись под scores.

## Фактическая Т04

В [debug-100-v4](../runs/debug-100-v4/) выполнены 34 оценки. Первые ответы модели:
28/28 корректны по JSON/OWL-синтаксису и на русском, без исправления первой попытки.
Валидность онтологии — отдельная проверка: валидны 20/34; остальные отклонены.
Лучший F=1.1246297491328545, воспроизведение совпало. Это отладочный результат,
не статистика основной серии.

Отдельная [проба контекста](../assessment/evidence/long-context-7b.json) обработала
32069 входных токенов и вернула контрольное слово из начала. На фактическом
MacBook Pro M4 Pro с 48 GB RAM LLM размещена полностью на GPU, сервер показывает
контекст 32768. Размер весов не выдаётся за универсальный минимум RAM/VRAM.

[Квалификация Т04](../assessment/evidence/qualification-v4.json) фиксирует хеши,
проверку языка, порога, контекста и исходников. Серии используют единственный
`series-v1.yaml`; после начала параметры не меняются. Прогноз 4.24 часа на серию
не заменяет фактическое измерение восьмичасового лимита.
