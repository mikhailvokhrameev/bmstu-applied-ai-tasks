# Подключение моделей: состояние подготовки

Доступен адаптер Ollama `/api/generate` и `/api/embed` через `OllamaModels`.
Запрос задаёт temperature=0.7, top_p=0.95, num_predict=2000, num_ctx=32768.
Установка num_ctx не подтверждает реальную поддержку контекста моделью.
`render_prompt` требует Manchester-представление текущего кандидата, M1–M6 и шесть ri;
полный шаблон находится в `prompts/proposal.txt`. OWL API проверяет синтаксис каждой
аксиомы и суммарно 1–5 логических аксиом; ограничения ядра, аннотации, DL и
допустимость изменений проверяет `validator.validate` отдельно.

Обнаружен локальный `qwen2.5-coder:3b`, файл весов 1 929 903 072 байт,
SHA-256 `4a188102020e9c9530b687fd6400f775c45e90a0d7baafe65bd0a36963fbb7ba`
(хеш фактически вычислен по blob). Это инвентаризация, а не выбор/квалификация
модели для серий. Версия сервера, параметры квантования, требуемая RAM/VRAM,
русский язык, реально доступный контекст >=32000 и производительность ещё не
подтверждены. Есть manifest `qwen3.5:397b-cloud`; он не является локальными весами.
По внешней sandbox проверке координатора `ollama list` отвечает и показывает обе
модели. Из sandbox HTTP `127.0.0.1:11434` недоступен: это не доказательство, что
сервер выключен. Локальной embedding-модели в списке нет.

`SemanticDeduplicator` использует текст «метка. комментарий» и сравнивает только
одинаковые category (значения OWL API: Class, ObjectProperty, DataProperty).
Передавайте полную таблицу существующих сущностей; callable проверяет также
совпадения между новыми сущностями одного предложения. Ошибки embedding-сервиса
не превращаются в результат «нет дубликатов». Нужны реальные embeddings и проверка
`assessment/concept_pairs.csv`: 10 синонимов и 10 разных понятий. `assess_pairs`
возвращает scores, ошибки и признак согласования; сам не меняет порог 0.90.
Текущие пары имеют pending_system_analyst. При ошибках новый порог устанавливает
системный аналитик и фиксирует решение до серий.

Реальный debug seed=100 (34 оценки), Т04 >=70% с первой попытки и оценка 8 часов
не проводились. Основные серии не разрешены до выполнения этих условий.
