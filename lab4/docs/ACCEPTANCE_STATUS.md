## Отчёт об экспериментах: пока не выполнены

Отладочный seed=100 и основные 101–105/201–205 НЕ ВЫПОЛНЕНЫ. Значения F, время,
доли ответов, U и p не приводятся. Технические журналы baseline/fixtures лежат в
assessment/evidence; они не являются результатами серий. Веб-OOPS! для исходника
и финала НЕ ВЫПОЛНЕНО; локальный Q0=10 нельзя выдавать за ответ сервиса.

После согласования Т04 сохраните реальные каталоги runs, config/metadata и полный
журнал; обработайте их analysis --replay --series. Для каждого числового результата
укажите путь запуска, ID кандидата, путь analysis.json и момент анализа. Зафиксируйте
время начала/окончания серий с прерываниями. Отдельно сохраните ответ OOPS!, снимки
Protégé и объяснение расхождений с локальными проверками.
