# Протокол испытаний BinaryMutation (план ТР-ВМ-001)

Дата запуска: 2026-10-26. Среда: Python 3.12.4, macOS. Метод — функциональное
тестирование «чёрным ящиком»; позиция мутации задана явно (`--position`).
Запуск: `python3 src/binary_mutation.py <строка> --position <N>` из `lab3/`.

## Контрольные примеры (таблица 1 ТЗ)

| № | Исходная строка | Позиция | Ожидаемый результат | Фактический результат | Статус |
|---|---|---|---|---|---|
| 1 | 00000 | 2 | 01000 | 01000 | пройден |
| 2 | 11111 | 3 | 11011 | 11011 | пройден |
| 3 | 101010 | 6 | 101011 | 101011 | пройден |
| 4 | 0 | 1 | 1 | 1 | пройден |
| 5 | 1001 | 2 | 1101 | 1101 | пройден |

Критерии прохождения (п. 6.6 ТЗ): фактическая строка совпадает с ожидаемой, длина
не изменена, различается ровно один разряд — выбранный. Для всех пяти примеров
критерии выполнены (разряд проверяется в `tests/test_binary_mutation.py`).

## Ошибочный ввод (п. 4.2 ТЗ)

| Вход | Фактическое поведение | Статус |
|---|---|---|
| пустая строка, `--position 1` | `Ошибка: пустая строка: длина должна быть не менее одного символа`, код 1, мутации нет | пройден |
| `10a1`, `--position 1` | `Ошибка: … недопустимые символы: 'a'`, код 1, мутации нет | пройден |
| `102`, `--position 1` | `Ошибка: … недопустимые символы: '2'`, код 1, мутации нет | пройден |
| `1001`, `--position 0` | `Ошибка: позиция 0 вне допустимого диапазона от 1 до 4`, код 1 | пройден |
| `1001`, `--position 5` | `Ошибка: позиция 5 вне допустимого диапазона от 1 до 4`, код 1 | пройден |
