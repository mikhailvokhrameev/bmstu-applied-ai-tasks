# Лабораторная работа 3. Программа, реализующая простую бинарную мутацию (BinaryMutation)

Консольная программа на Python 3.10+ (только стандартная библиотека), выполненная
по ТЗ [`Техническое_задание_бинарная_мутация_3.pdf`](Техническое_задание_бинарная_мутация_3.pdf).

Работа относится к теме «Бионические вычисления» (лекция 7: эволюционные алгоритмы
как метод, имитирующий биологические процессы, входят в мягкие вычисления; по Заде
к ним относятся и генетические алгоритмы). Определение мутации, нумерация позиций и
критерии испытаний взяты из ТЗ.

## Что делает программа

Под бинарной мутацией понимается инверсия одного выбранного бита: `0` заменяется на `1`,
`1` — на `0`; остальные разряды не меняются. Программа:

- принимает двоичную строку из символов `0` и `1` (длина не менее одного символа);
- выбирает позицию мутации случайно из диапазона от 1 до длины строки либо берёт
  фиксированную позицию (`--position`), либо воспроизводимую случайную (`--seed`);
- инвертирует бит в выбранной позиции;
- выводит исходную строку, номер мутированного разряда и строку после мутации.

Позиции нумеруются слева направо, начиная с единицы.

## Запуск

Из папки `lab3/`:

```bash
python3 src/binary_mutation.py 1001 --position 2   # тестовый режим, фиксированная позиция
python3 src/binary_mutation.py 101010 --seed 7     # случайная позиция, воспроизводимо
python3 src/binary_mutation.py 101010              # случайная позиция
python3 src/binary_mutation.py --position 2        # строка запрашивается с клавиатуры
```

Пример вывода для `python3 src/binary_mutation.py 1001 --position 2`:

```text
Исходная строка: 1001
Позиция мутации: 2
Строка после мутации: 1101
```

Параметры `--position` и `--seed` взаимоисключающие.

## Обработка ошибок

При пустой строке, символах кроме `0` и `1` или позиции вне диапазона `1..длина`
программа печатает сообщение вида `Ошибка: …` в stderr, не выполняет мутацию и
завершается с кодом 1.

## Испытания

```bash
python3 -m unittest discover -s tests -v
```

Тесты проверяют пять контрольных примеров из таблицы 1 ТЗ (совпадение с ожидаемой
строкой, неизменная длина, ровно один изменённый разряд — выбранный), ошибочный вход,
случайный режим и вывод CLI. Протокол испытаний — [`docs/test_protocol.md`](docs/test_protocol.md).
