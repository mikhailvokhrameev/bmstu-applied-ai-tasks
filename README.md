# ПЗИИ — лабораторные работы

Репозиторий содержит лабораторные работы по предмету **«ПЗИИ»** (МГТУ им. Баумана, 7 семестр). Каждая работа лежит в
своей папке, самодостаточна и запускается из неё; подробное описание, команды
запуска и ограничения — в `README.md` соответствующей лабораторной.

### Лабораторная работа 1. Экспертная система технического осмотра автомобилей

Система на SWI-Prolog в диалоге задаёт 25–27 вопросов о состоянии автомобиля и
выдаёт заключение («допущен», «допущен с замечаниями», «не допущен»),
перечень несоответствий по семи группам узлов с тремя степенями критичности,
рекомендуемое действие и объяснение вывода с номерами сработавших правил.

- база знаний из двух слоёв: 52 правила несоответствий (P01–P52) и 8 правил
  заключения (V01–V08) над 28 признаками;
- пороговые значения вынесены в отдельный модуль с источниками;
- обнаружение противоречивых и недостаточных входных данных;
- автоматические проверки: 13 приёмочных испытаний по ТЗ, границы порогов,
  проверка базы знаний на конфликты правил.

Запуск: `swipl -q -s src/expert_system.pl -g start -t halt` из `lab1/`,
тесты — `./scripts/run_tests.sh`. Подробнее — [`lab1/README.md`](lab1/README.md).

### Лабораторная работа 2. Онтология «Дискретные видеокарты» (VideoCardOntology v1.0.0)

Учебная OWL 2 DL онтология предметной области «Видеокарта»: модели видеокарт,
их GPU, конфигурации видеопамяти, охлаждение, интерфейсы подключения,
видеовыходы, производители и назначения. Выполнена по ТЗ «Онтология предметной
области Видеокарта»; файл — RDF/XML, основной reasoner — HermiT.

- 13 классов и 2 определяемых класса, 10 объектных свойств, 7 свойств данных,
  41 именованный индивид (8 учебных моделей), 472 аксиомы;
- онтология собирается из Python-генератора (`ontology/src/`), контрольная
  сумма `videocard.owl` зафиксирована в README;
- тестовая оснастка на Java (OWL API + HermiT): испытания T01–T11 — обязательные
  сущности, структура и полнота данных, согласованность, 8 контрольных
  DL-запросов, отрицательные тесты с намеренными дефектами, round-trip
  сохранение и проверка комплекта поставки;
- описание онтологии и протокол испытаний — в `lab2/docs/`.

Запуск испытаний: `bash tests/run_tests.sh` из `lab2/`. Подробнее —
[`lab2/README.md`](lab2/README.md).
